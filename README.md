# Deal OS MVP

A lightweight, no-integration MVP that captures deal reality, tracks proof plans, and maintains living artefacts. This is a single-page app with local storage so enterprise AEs can validate the workflow without any backend.

## What this MVP covers

- Deal home with stage, next actions, risks, and proof gaps.
- Proof dashboard with explicit evaluation vs implementation tracks.
- Stakeholder map with mobiliser plan notes.
- Versioned artefacts (exec brief, follow-up email, MEDDPICC snapshot).
- Timeline of key events.
- Daily action items digest.

## Run locally

Open `index.html` in a browser. No build step required.

## Data storage

All data is stored in your browser's local storage under the key `deal-os-mvp`.
